If you're new here: DLSS5 Updater finds your games and installs or updates OptiScaler, DLSS, ReShade with its add-ons, HDR mods, DXVK and frame limiters, with a backup of every file it replaces. See the [README](https://github.com/ApolloF/DLSS5-Updater#readme) to get started.

This is a big one. The app now reads a catalog of mods and games ([ApolloF/DLSS5-Updater-catalog](https://github.com/ApolloF/DLSS5-Updater-catalog)) that updates every 6 hours, so new mods and builds show up without an app update. Every download from it is checked against its SHA-256 before it goes anywhere.

## Neural rendering files are downloaded for you
- `nvngx_dlssnr.dll`, Lecram's DLSS5 add-on and ShortFuse's RenoDX DLSS add-on are now downloaded and installed automatically. You don't have to find them yourself anymore.
- Importing your own files still works, and everything already in your library stays.

## Works in this game
- The game page has a new Works in this game panel. It lists what fits that game (DLSS update, the NR add-ons, OptiScaler, DLSS5-Feeder with Deep Fried Chicken, MFG Unlock, Smooth Motion and so on) with a short reason, and Select turns on the right components. Things that won't work in that game are listed too, with why.
- New: DLSS5-Feeder, a ReShade add-on that makes the DLSS calls in games that have no DLSS, so Deep Fried Chicken can run there. DLAA only.
- The game page shows what the app detected: graphics API, 32 or 64-bit, engine and Unreal version. If it got something wrong, set it yourself under Detection, same for the main exe, the mod folder and the Engine.ini path.
- Battle.net and Rockstar games are found now.

## HDR mods
- RenoDX HDR: the app picks the mod for the game, or the generic Unreal or Unity one, installs ReShade if the game has none and writes the Engine.ini lines. Peak brightness is one setting for all games.
- Luma: the same for Luma Framework mods, per game or the generic Unreal one. Launch options are shown with a Copy button, since the app can't set those in Steam for you. If a mod needs dgVoodoo the app tells you and links it.
- You can pick any mod by hand or import your own add-on or Luma zip. RenoDX and Luma on the same game gives a warning, you can still install both.

## DXVK
- DXVK for DX8 to DX11 games, in three flavours: Stable, Development and the Lilium HDR fork. Your own dxvk.conf values win over ours.
- Lilium sets the NVIDIA present method it needs and puts the old value back when you remove it.
- If ReShade sits under the same dll name, it moves to its Vulkan layer after you confirm.

## ReShade
- ReShade is fully managed now: a library with Stable, Stable without add-ons, Nightly, Legacy and your own imports. Newest Stable is the default and each game can pick its own.
- The dll gets the right name for the game's graphics API, and 32-bit games get the 32-bit build.
- Vulkan games use the ReShade Vulkan layer, installed from Settings (asks for admin once).
- If another dll already has that name (another ReShade, OptiScaler, DXVK, Special K, ENB), the app tells you what it found and backs it up.
- New Add-ons & shaders tab on the game page: ReShade add-ons, shader packs and presets from the catalog, or your own. Your own ini values win over ours.

## Frame limiters
- Frame limit per game: NVIDIA driver cap, ReLimiter, Display Commander or the Unreal `t.MaxFPS` cap. Auto picks one, you can change it per game.

## NVIDIA profile
- A lot more on the NVIDIA profile tab: DLSS presets per feature, render mode, MFG, Smooth Motion, RTX HDR, VSync, low latency and the frame rate limiter. Options your driver doesn't know are hidden.
- Reset to previous puts back exactly what the profile had before the app touched it. Uninstall now also puts back what DXVK and the frame limiter changed in the driver.

## Warnings instead of blocks
- Things that don't go well together (two NR add-ons, OptiScaler's MFG unlock next to MFG Unlock, games with anti-cheat, Store games) now show a warning with the reason, and you can install anyway. The warning stays visible on the game. Auto never picks a combination like that.
- "Allow more than one NR add-on" is gone, you confirm it per game instead. A Store folder that Windows locks still can't be installed into.

## Other
- Every pick the app makes on its own can be changed per game, with Auto first and Reset to auto.
- When GitHub rate-limits the app, a banner says so with the time it resets and a button to add a token.
- Uninstall leaves a file alone if you or the game replaced it after the app installed it.
