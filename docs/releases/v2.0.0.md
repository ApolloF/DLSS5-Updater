If you're new here: DLSS5 Updater finds your games and installs or updates OptiScaler, DLSS, Streamline, MFG Unlock, ReShade and a few add-ons, with a backup of every file it replaces. See the [README](https://github.com/ApolloF/dlss5updater#readme) to get started.

## New name
DLSS Updater is now called DLSS5 Updater. The files are now `DLSS5Updater.exe` and `DLSS5Updater-Setup-2.0.0.exe`, and the project lives at [ApolloF/dlss5updater](https://github.com/ApolloF/dlss5updater) (the old link redirects).

Updating keeps everything:
- On first start the app moves `%LocalAppData%\DLSSUpdater` to `%LocalAppData%\DLSS5Updater`, with your settings, downloads, imported components and log. If a file there is in use, it keeps using the old folder and tries again next start.
- Games you installed into keep their backups, so Uninstall and Restore DLSS still put back the original files.
- The installer updates an existing install in place, removes the old `DLSSUpdater.exe` and renames the Start menu and desktop shortcuts. Close the app before running it; setup asks if it is still open.
- Portable version: replace `DLSSUpdater.exe` with `DLSS5Updater.exe`.
- Taskbar or Start pins and Steam shortcuts that point at the old `DLSSUpdater.exe` stop working. Pin or add `DLSS5Updater.exe` again.

## The app updates itself
- DLSS5 Updater checks GitHub for a newer version at start (at most every 6 hours) and shows an Update button in the title bar. Settings → General has Check now, the release notes and an opt-in "Install updates automatically", which installs when you close the app, never in the middle of a job.
- Updates are only installed when the download matches the checksum published with the release (`SHA256SUMS`, new from this release on). The installer version runs setup silently and restarts the app; the portable version swaps its exe.
- This starts with 2.0.0, so you install 2.0.0 itself by hand. Automatic installs skip machine-wide installs to avoid a surprise admin prompt; use the Update button there.

## First-run setup
- A fresh install opens a short setup: what the app does, how games should be set up (OptiScaler, or ReShade + add-ons, the DLSS5 mod route, with one NR add-on), and update and download options. Skip works on every step and keeps the defaults. Settings → General → Run setup again brings it back. Updates from 1.x don't show it.

## Build libraries and cleanup
- OptiScaler (both forks) and GITC Uplift builds now stay in a library like Lecram's and ShortFuse's. Pick a default in Settings, or a specific build per game on its Install tab.
- Every build list shows the newest build on top.
- Settings → General → Build library shows how much each library holds. Keep newest N (2 by default) and "Clean up old builds" free the space. "Delete old downloads automatically" is off by default and only ever removes old downloads; builds you imported stay until you clean up by hand.
- Cleanup never removes a default, a build a game uses or picked, or the NR runtime a game can switch back to, also for games that are hidden or on a drive that isn't plugged in.

## OptiScaler F5 by default
- New installs start on OptiScaler F5 (janblade). Existing installs keep the build you chose. OptiScaler-NR is still one click away in Settings or per game.

## One NR add-on at a time
- ShortFuse's RenoDX add-on, Lecram's DLSS5 add-on and GITC Uplift are now exclusive: turning one on turns the others off, in Settings and per game. "Allow more than one NR add-on" lets ShortFuse and Lecram run together again (NR then runs twice; a small note says so). Settings that already had ShortFuse and Lecram on keep working.
- The "this pair hasn't been tested together" note is gone; a pair you marked as crashed still warns.

## Other
- Labels, help texts and logs name the OptiScaler build you picked (OptiScaler-NR or OptiScaler F5).
- Every component on a game's Install tab has an info button that explains what it is and when to turn it off.
- "Download ReShade from reshade.me" moved under the ReShade64.dll row in Settings.
