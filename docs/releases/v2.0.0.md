If you're new here: DLSS5 Updater finds your games and installs or updates OptiScaler, DLSS, Streamline, MFG Unlock, ReShade and a few add-ons, with a backup of every file it replaces. See the [README](https://github.com/ApolloF/dlss5updater#readme) to get started.

## New name
DLSS Updater is now called DLSS5 Updater. The files are now `DLSS5Updater.exe` and `DLSS5Updater-Setup-2.0.0.exe`, and the project lives at [ApolloF/dlss5updater](https://github.com/ApolloF/dlss5updater) (the old link redirects).

Updating keeps everything:
- On first start the app moves `%LocalAppData%\DLSSUpdater` to `%LocalAppData%\DLSS5Updater`, with your settings, downloads, imported components and log. If a file there is in use, it keeps using the old folder and tries again next start.
- Games you installed into keep their backups, so Uninstall and Restore DLSS still put back the original files.
- The installer updates an existing install in place, removes the old `DLSSUpdater.exe` and renames the Start menu and desktop shortcuts. Close the app before running it; setup asks if it is still open.
- Portable version: replace `DLSSUpdater.exe` with `DLSS5Updater.exe`.
- Taskbar or Start pins and Steam shortcuts that point at the old `DLSSUpdater.exe` stop working. Pin or add `DLSS5Updater.exe` again.

## Other
- Labels, help texts and logs name the OptiScaler build you picked (OptiScaler-NR or OptiScaler F5).
