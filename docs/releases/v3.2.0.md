## Fixes
- MFG Unlock next to OptiScaler now installs ReShade with it. MFG Unlock is a ReShade add-on, and without ReShade it never loaded.
- Some games load the mod files from a different folder than the one their exe runs from (Phantom Blade Zero runs `platform\steam\PBZ.exe`). OptiScaler looks for ReShade and its frame generation plugins next to the exe, so there they never loaded. Once the game has run, the app reads that from ReShade's or OptiScaler's log and tells you which install folder to pick.
- GITC Uplift 1.8.0 to 2.0.0 can crash a game at start when something else also hooks Streamline's swap chain, for example Unreal's FSR frame generation in Phantom Blade Zero. The app warns about it and points to Uplift 1.7.0 for those games until the upstream fix is released.
- Originals the app backs up are stored under a name other mods don't pick up. Before, OptiScaler could find the game's old DLSS in the backup folder and use it.

## Works in this game
- The cards now depend on the game, not on which rows are ticked. Ticking a row by hand no longer swaps cards out, and a DLSS game shows every neural add-on you have side by side.
- The highlighted card follows the component table both ways. When two cards match, the one you clicked wins.
- Picking a neural card turns the other neural add-ons off.
- Turning MFG Unlock on in OptiScaler mode turns ReShade on. Turning ReShade off turns MFG Unlock off, since it can't load without it.
- Importing a build or downloading the NR runtime refreshes the cards right away.
