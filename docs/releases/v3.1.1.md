## ShortFuse RenoDX
- Builds are named by the build stamp in their About section (for example `26.0928.0205`), the same name the catalog uses. Before, the list showed the file version, which never matched the catalog. Builds you already have get the new name on the next start, and the file version still shows in the build's details.
- No more import date next to the build names.
- A catalog build you already imported by hand isn't offered for download again.
- The picker shows your builds plus only the five newest catalog builds you don't have, newest first.

## MFG Unlock
- MFG Unlock is a tick box under the method cards now, on top of whichever method you pick, instead of a method of its own. Before, picking it dropped your NR add-on or OptiScaler, and picking a method dropped MFG Unlock again. It also works with no method picked.
- It was broken since 3.0.0. If MFG Unlock didn't stick for you, it should now.
