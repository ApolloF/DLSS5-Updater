## Deep Fried Chicken library
- Every DFC import now stays in a library, like Lecram's and ShortFuse's add-ons. The default follows the newest build unless you pick one, and each game can use its own build from the game page.
- Your current import moves into the library on first start, and games that already have DFC are matched to it.
- DFC builds are in the cleanup too. Imported builds only go when you clean up by hand.

## Lecram
- Lecram's builds are paid on his Buy Me a Coffee now, so the app doesn't fetch them from his download folder anymore. Get the add-on from him and import it in Settings → Local components. Builds you already have stay in the library.
- The Lecram default now follows the newest build in your library instead of sticking to the one that was default when you first imported. Pick a build if you want to keep using an older one.

## Cleanup
- Each library row in the cleanup section now says why builds beyond the keep count stay, for example because a game still has that build installed or picked. OptiScaler shows how many builds each source keeps.
