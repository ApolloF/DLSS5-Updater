## Main window
- Install, DLSS only, Restore DLSS and Uninstall now sit in a bar under the game page that stays put while you scroll, with progress and Cancel while something runs.
- Clicking a method card applies it right away. The separate Use button is gone.
- The component strip folds into one summary line, and the app remembers if you left it open.
- Settings General is split into Components, Defaults and App.
- The window opens where you closed it. Ctrl+F jumps to the game search, Restore DLSS asks first, and Reset to defaults is now called Reset mod settings since it never touched the app settings.
- Plainer texts on the cards and pickers, and a bunch of small fixes.

## OptiScaler F5
- Works with F5 0.1.34. F5 renamed its release files, so if you were stuck on 0.1.32 the app finds the new builds again and updates.
- The DLSS-G and Streamline files that come with F5 are no longer mistaken for the game's own and get left alone.
- HDR and MFG unlock settings follow the F5 version you install. Keys a newer F5 dropped are removed on update, with a line in the log.
- Games where the app set Force HDR have HDR output off after updating to F5 0.1.33 or newer. Turn on "HDR output" again on the game page.
- The help has a note for RTX 30 cards about games hanging when their own frame generation is on and an nvngx_dlssg.dll sits in the OptiScaler folder.

## Lecram
- Supports v11.9.0 and v12.0.0. NRPresentFgPath is gone in v12, so it's hidden there and an old value gets dropped.
- ForeignNr is only set to observe automatically on v10 and v11. v12's own default already works next to ShortFuse's add-on.
- Old builds no longer show up as v310.8.0 (that's the DLSS SDK version) and existing library entries get the right label.

## Other
- OptiScaler-NR v0.9.72 and GITC Uplift 1.6.2. GITC has a new AllowCrossQueuePasses option, off by default.
- MFG Unlock has an XeMFG backend for RTX 20 and 30 now, so Works in this game shows it as needs setup on those cards instead of not possible.
