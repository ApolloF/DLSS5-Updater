## Deep Fried Chicken 5.0
- Deep Fried Chicken is checked up to 5.0.0. Its config is the same as 4.0.6 apart from the default NR preset, which you pick in the overlay (Game, Preset A or Preset B).
- The import now takes the whole 64-bit folder, like DFC's README says, instead of a fixed list of files. Logs, the cfg and the nvngx/ReShade files you might have dropped in there are left out, since the app places those itself.
- Settings → Local components has a new Folder… button for the extracted release folder (or its 64-bit folder), and Import… also takes a .zip. The .7z from the release post is password protected, so extract that one first.
- Every DFC file placed in a game is recorded now, so uninstalling or switching to another NR add-on takes all of it out again, also files a newer DFC adds or drops.
