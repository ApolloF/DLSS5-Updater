If you're new here: DLSS Updater finds your games and installs or updates OptiScaler, DLSS, Streamline, MFG Unlock, ReShade and a few add-ons, with a backup of every file it replaces. See the [README](https://github.com/ApolloF/dlssupdater#readme) to get started.

## Safer installs
- Every file swap is staged first. If a copy fails (disk full, antivirus), the game keeps its original file.
- The install record is saved as it goes, so a crash or a killed process can't leave an original file unrecorded.
- Changing the proxy file name removes the old proxy and puts back the file it replaced.
- Unticking MFG Unlock or ReShade now removes them from the game, and Update all no longer brings them back.
- Two install folders in one game no longer back up each other's DLSS files, so uninstalling in any order restores the real originals.
- Read-only files (for example an ini you locked) are replaced and restored instead of failing with an administrator prompt.
- Fresh config keeps one copy of the previous config file.

## More reliable
- Only one job runs at a time, so an install and an uninstall can't run on the same game together.
- An expired GitHub token no longer keeps the app on old release data.
- Cancel really cancels an update check.
- One unreadable Steam library no longer hides all Steam games.
- Settings are safer: an unreadable settings file is kept as `settings.json.bad`, and only one copy of the app runs at a time.
- Two options whose real default is On (RenoDX Character mask, and Run before upscaling in OptiScaler-NR) showed Off. They now offer Default, On and Off.

## Clearer and more accessible
- Plain, consistent names and help texts across the app, and help texts corrected where they didn't match what the app does.
- Visible keyboard focus everywhere, screen reader names for all buttons and inputs, Esc closes Settings and About.
- Better contrast and slightly larger small text.
- Error messages say what happened in plain words; technical details go to the log.
- Fixed the maximise button showing garbled characters.
