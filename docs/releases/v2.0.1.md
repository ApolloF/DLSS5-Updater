## Lecram DLSS5 v11 Patch 11
- Lecram's add-on is checked up to v11 Patch 11 (`v11.0.0-beta.48`), which the app fetches from the author's public channel. Patch 10 (`beta.45`) was checked too.
- New option "Present with frame generation" (Settings → ReShade add-ons → Lecram, and per game). It is the author's test option `NRPresentFgPath`: "Real frames only (test)" runs NR once per real frame at frame generation's call. Leave it on the add-on default unless NR blinks at Present with frame generation.
- The Preset options now use the add-on's own names, Old (preset 1) and New (preset 2). The values didn't change.
- Options a Lecram build doesn't know yet are hidden for that build and not written to its ReShade.ini, and a key the app wrote for a newer build is taken out again when a game switches to an older one.
